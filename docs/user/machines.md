# Machine resources

Open **Machines** from the bottom of the sidebar rail or the command palette. On mobile, open
**Settings** and choose **Machines** at the top.

**Machines** shows each machine you are connected to, this one first: CPU use with its core count
and 1, 5 and 15 minute load averages, memory, swap, free disk space and how long the machine has been
up. Hover **Machines** in the rail for CPU, memory and disk on every machine without leaving your
thread.

Values refresh every 5 seconds while the page or the hover summary is on screen, and machines are
not asked otherwise. A value turns amber at 80% and red at 90%.

Disk space is for the drive that holds the machine's T3 home, where its worktrees live. Windows
machines show no load average or swap. A machine running an older T3.CodeShip shows only CPU
and memory until it is updated. An offline machine shows when it was last seen and a button to
reconnect it.
